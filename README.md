# 🎮 Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The player competes against the computer, which generates a random move each round. The game instantly displays the result, updates the score, and provides a clean, responsive interface.

## 🚀 Live Demo

🔗 https://deepak-thakur2004.github.io/rock-paper-scissors/

## 📌 Features

- 🎮 Play against the computer
- 🤖 Random computer move generation
- 🏆 Automatic winner detection
- 📊 Real-time score updates
- 💬 Dynamic result messages
- 🎨 Responsive and user-friendly interface
- ⚡ Fast and lightweight application

## 🎯 How to Play

1. Click on **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its choice.
3. The winner is determined using the game rules:
   - 🪨 Rock beats Scissors
   - ✂️ Scissors beat Paper
   - 📄 Paper beats Rock
4. The score and result message update automatically after every round.
